# Security timeline

**What it shows:** one time axis, with a row for the security field at the top and a row for each other field below.
Each bar counts the milestones that became real-world change in a period (one, two, five or ten years, depending on
the space available). Solid bars are landed milestones; pale bars are outlook milestones, whose years are AI
estimates. Security bars are coral; technology bars are teal. Bar heights use a square-root scale, so a period with a
single milestone still shows; the exact counts are in each bar's tooltip and the side panel. It shows, at a glance, when security work arrived
compared with the technologies around it.

**How to use it:** open Charts, choose the ✨ Security timeline tab. Select a bar to list, in the side panel, that
field's milestones in that period beside the security milestones of the same period; each opens its story. Select a
field's name (or its button under the chart) for a summary: how many landed, the first year, the year by which half
had landed, and the same for security. It follows your filters.

**Insight:** the year by which half of the landed security milestones had arrived, against the same year for the
landed technology milestones, with both counts. Every figure comes from the data.

**Honesty:** security milestones are not matched to a technology here: the extension interface does not give the
technology's category of attack or the researched security response. The app's own Security lag chart and Cyber
lens match them by category. Milestones in the lab, with no change year, are left out. The data is AI-compiled from
public sources and may contain errors.

**Why it was added:** 5 November 2026, for idea issue #36 ("A simple timeline of when the security response arrived
for each technology in its category"). A per-technology version needs data the interface does not provide, so this
chart gives the field-level timeline, and points to the Security lag chart for the matched responses.
